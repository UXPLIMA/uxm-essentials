# A menu is a file, and this is the whole menu: its title, its size, and every tile in it.
#
# Open it in game with /menu open <name>, where <name> is this file's name without .conf.
# Copy the file to menus/<your-name>.conf to start one of your own.
#
# A tile is one block under items {}. It needs a slot and a material. Everything else is
# optional: name, lore, and a click {} block that says what each mouse button does.
#
# A name and a lore line are written as MiniMessage and shown as written, so style them
# however you like. {player} becomes the name of the player who opened the menu. A title, name
# or lore line written as @key reads a message catalogue entry instead, in the viewer's
# language: add the key to messages/messages_<lang>.conf and write @custom.my-line here.
# Arguments follow the key as name=value and fill the entry's {name} tokens.
#
# The in game editor writes this file. It writes back the menu it is holding, so it keeps
# this header and it does not keep a comment you wrote yourself, and it sorts the keys. Keep
# your own notes somewhere the editor does not rewrite.
