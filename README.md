# uxmEssentials

The all-in-one essentials suite for Paper 26.2: 35 modules, from homes, warps and economy to moderation, NPCs and holograms

Paper 26.2+, Folia ready. uxmLib is shaded into the jar, so the plugin needs nothing else on the server.

## Install

Download `uxmEssentials-<version>.jar` from the latest GitHub release, check it against `SHA256SUMS`, put it in
`plugins/` and start the server. The files it writes are listed in [docs/user/reference.md](docs/user/reference.md).

## Build

```sh
./gradlew build       # format check, static analysis, the shaded jar and its check
./gradlew runServer   # a local Paper server with the plugin
```
